# VERTEX Logistics & Transport — Apps Workspace Directory

This directory is the root for deployable applications in the monorepo:
- `apps/api`: NestJS Backend API Engine (Planned for Step 2.3)
- `apps/customer-web`: Next.js Customer Web & Public Tracking Portal (Planned for Step 2.4)
- `apps/business-portal`: Enterprise B2B Management Portal (Phase 5)
- `apps/employee-admin`: Internal Operations Console (Phase 3)
- `apps/worker`: BullMQ Background Job Worker (Phase 2)

2. `DEVELOPMENT_ROADMAP.md` - Phased implementation schedule and deliverables.

4. `ARCHITECTURE_DECISIONS.md` - Architecture Decision Records (ADRs).

7. `SECURITY_CHECKLIST.md` - Security controls, tenant isolation, and verification rules.
8. `TESTING_STATUS.md` - Test pyramid execution metrics.
